# Changelog

Todas las modificaciones notables de este proyecto serán documentadas en este archivo.

## [1.1.0] - 2026-03-15

### Añadido
- Campo configurable para número de cartas a robar en "Robo Natural" (Draw 1, Draw 2, Draw 3, etc.)
- Footer discreto con créditos "powered by MetalEmpire TCG Team"

### Modificado
- Campo de cartas a robar posicionado al final del formulario antes de los botones de acción

## [1.0.0] - 2026-03-11

### Añadido
- Calculadora de probabilidades hipergeométricas para Digimon TCG
- Soporte para múltiples tipos de búsqueda: Cool Boy, Memory Boost, Memory Boost Dual, Training, Robo Natural y Custom
- Sistema de temas claro/oscuro con persistencia

# Designs

Esta carpeta contiene todos los diseños, mockups y wireframes del proyecto.

## Contenido Esperado

- Mockups de componentes individuales
- Flujo de usuario completo
- Paleta de colores y guía de estilo visual
- Diseños responsive (desktop/tablet/mobile)
- Capturas de pantalla de referencia
- Prototipos interactivos (Figma, Adobe XD, etc.)

## Formato Recomendado

- PNG, SVG para imágenes estáticas
- Figma links o archivos `.fig`
- Adobe XD links
- Sketch files
- PDF para documentación de diseño

## Estructura Sugerida

```
designs/
├── mockups/
│   ├── deck-configuration.png
│   ├── card-tracker.png
│   ├── search-selector.png
│   └── probability-results.png
├── wireframes/
│   ├── layout-desktop.png
│   └── layout-mobile.png
├── user-flow/
│   └── complete-flow.png
└── style-guide/
    ├── color-palette.png
    └── typography.png
```

## Convenciones de Nombres

- Usar kebab-case: `component-name-variant.ext`
- Incluir viewport en el nombre si es relevante: `component-mobile.png`
- Versionar si es necesario: `component-v2.png`

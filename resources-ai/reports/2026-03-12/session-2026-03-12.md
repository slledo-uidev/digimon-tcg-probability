### 7. Refactorización Atomic Design

**Objetivo:** Dividir monolito de Calculator en componentes pequeños.

**Estructura implementada:**

#### Organisms (`components/organisms/`)
- `calculator/`: Componente contenedor principal

#### Molecules (`components/molecules/`)
- `calculator-header/`: Encabezado con título y tema
- `calculator-form/`: Formulario de parámetros
- `calculator-results/`: Sección de resultados
- `result-card/`: Tarjeta individual de resultado

**Arquitectura:**
```
app.component
  └── calculator (organism)
       ├── calculator-header (molecule)
       ├── calculator-form (molecule)
       └── calculator-results (molecule)
            └── result-card (molecule) x N
```

**Beneficios:**
- Componentes legibles y mantenibles
- Reutilización facilitada
- Testing simplificado
- Separación de responsabilidades

### 10. Cálculo Manual en Móvil

**Objetivo:** Evitar recálculos automáticos en mobile.

**Problema anterior:**
- Cambios en inputs recalculaban instantáneamente
- Auto-colapso indeseado
- UX confusa

**Solución:**
- Detección de viewport: `isMobileView()`
- Desktop: cálculo reactivo (actual)
- Mobile: cálculo solo al pulsar "Calcular Probabilidades"
- Prevención de auto-colapso hasta submit explícito

**Implementación técnica:**
```typescript
onInputChange(): void {
  if (!this.isMobileView()) {
    this.calculateProbabilities();
  }
}
```

### Estándares Aplicados

#### 1. SCSS con BEM Anidado
```scss
.block {
  property: value;
  
  @media (min-width: $theme-breakpoint-md) {
    property: other;
  }
  
  &__element { }
  &--modifier { }
}
```
